# Simple Interest Calculator

A simple calculator that computes simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

The calculator takes the following inputs:
- Principal amount
- Rate of interest
- Time period

## Usage

Run the `simple-interest.sh` Bash script and enter the principal, rate of interest, and time period when prompted.
